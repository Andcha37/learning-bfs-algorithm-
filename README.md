# BFS(너비 우선 탐색) 알고리즘 프로젝트

본 프로젝트는 **BFS(Breadth-First Search, 너비 우선 탐색)** 알고리즘의 핵심 원리를 이해하고, 이를 파이썬 순수 내장 문법만으로 구현하여 다양한 실생활 문제 및 그래프 이론에 적용해 보는 것을 목표로 합니다.

---

## 1. 도입 및 핵심 개념 (Introduction & Core Concepts)

- **그래프 이론 기초**: 정점(Node)과 간선(Edge)의 개념 및 방향/무방향 그래프의 차이점 이해.
- **Queue 자료구조 (FIFO)**: BFS의 핵심 엔진인 큐의 선입선출(First In First Out) 작동 방식. 
- **BFS 알고리즘 정의**: 시작점에서 가까운 거리(레벨) 순서대로 파문이 일듯 퍼져나가는 탐색 방식. 가장 가까운 노드를 우선적으로 탐색하기 때문에 최단 거리 찾기에 최적화되어 있습니다.
- **탐색의 동기 (실생활 예시)**: "학교에서 집으로 가는 길, 지금 가는 길이 정말 최단 거리일까?" 복잡한 네트워크 환경에서는 직관만으로 최단 경로를 찾기 어렵기 때문에 BFS와 같은 알고리즘이 필수적입니다.

## 2. 프로젝트 목표 및 알고리즘 원리

- **알고리즘 원리 시각화**: BFS가 레벨 구조로 그래프를 탐색하며, 비가중치 그래프에서 첫 방문 경로가 곧 최단 경로임을 보장하는 원리를 시각 자료와 함께 분석합니다.
- **복잡도 (Complexity) 분석**:
  - **시간 복잡도 (Time Complexity) - $O(V+E)$**: "얼마나 빨리 찾을 수 있는가?" (연산 속도)
  - **공간 복잡도 (Space Complexity) - $O(V)$**: "얼마나 넓은 자리가 필요한가?" (메모리 사용량)

## 3. 시스템 설계 및 코드 구현

본 프로젝트의 구현은 외부 라이브러리 의존성을 없애고 자료구조의 본질을 이해하기 위해 기획되었습니다.

- **5대 핵심 모듈**: 
  1. 그래프 생성
  2. BFS 탐색
  3. 최단 경로 복원
  4. 예외 처리
  5. 결과 출력 모듈

- **사용 기술 및 차별점 (Pure Python Implementation)**: 
  - 통상적으로 사용하는 `collections.deque` 모듈을 **배제**합니다.
  - 오직 **파이썬 기본 내장 리스트(`list.append()`, `list.pop(0)`)와 딕셔너리(`dict`)만**을 활용하여 인접 리스트 구축 및 Queue 자료구조를 직접 구현합니다. 
  - 이를 통해 `deque`를 사용할 때와 기본 리스트를 사용할 때의 내부 작동 원리 차이점을 깊이 있게 학습합니다.

- **경로 탐색 실증**: 
  - 구현한 BFS 코드를 **서울 지하철 최단 경로 찾기** 및 **2D 격자형 미로 탈출** 등에 적용하여 동적으로 동작하는 시각화 자료를 제공합니다.

- **이분 그래프 판별 (Bipartite Check)**:
  - 단순 탐색을 넘어, 대규모 데이터 전처리 단계에서 BFS 기반 **2-Coloring 기법**을 사용하여 그래프의 이분성을 검증하는 시스템을 구현했습니다.

## 4. 결론: 장단점 및 향후 과제

- **장점**: 
  - 알고리즘의 논리적 실행 흐름이 인간의 직관과 비슷하여 구현이 상대적으로 명확합니다.
  - 비가중치 그래프에서 **최단 경로(Shortest Path)**를 찾는 데 매우 빠르고 강력합니다 (DFS와의 가장 큰 차별점).
- **단점 (한계점)**: 
  - 그래프의 규모(너비)가 커질수록 Queue에 저장해야 하는 노드가 급격히 늘어나 **메모리(공간 복잡도) 사용량이 급증**합니다.
  - 간선마다 가중치(거리, 비용 등)가 다를 경우 일반적인 BFS 알고리즘을 통한 최단 경로 탐색이 불가합니다.
- **향후 과제 (한계 극복)**: 
  - 가중치가 있는 네트워크망(예: 내비게이션 등)의 최단 거리를 구하기 위해 **데이크스트라(Dijkstra)** 등 발전된 알고리즘의 추가 연구가 필요합니다.
