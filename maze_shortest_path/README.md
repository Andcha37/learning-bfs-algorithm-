# BFS 미로 최단 경로 탐색

이 코드는 미로에서 시작점 `S`부터 목표점 `G`까지 이동할 수 있는 최단 경로를
BFS(Breadth-First Search, 너비 우선 탐색)로 찾는 예제입니다.

BFS는 시작점에서 가까운 칸부터 차례대로 탐색합니다. 그래서 모든 이동 비용이
같은 미로에서는 목표점에 처음 도착했을 때의 경로가 최단 경로가 됩니다.

이번 구현에서는 파이썬 표준 라이브러리의 `collections.deque`를 사용하지 않고,
head-tail 방식의 큐를 직접 만들어 사용했습니다.

## 파일 구성

```text
bfs.py
```

`bfs.py` 안에는 미로를 그래프로 바꾸는 함수, 직접 구현한 큐, BFS 탐색 함수,
경로 복원 함수가 들어 있습니다. 핵심 알고리즘은 아래 네 부분으로 구성됩니다.

## 코드 구성

### 1. 미로를 그래프로 변환

```python
maze_to_graph(maze)
```

미로는 2차원 리스트로 표현합니다.

- `S`: 시작점
- `G`: 목표점
- `.`: 이동 가능한 칸 (실제 코드에서는 '#'이 아닌 문자는 모두 이동 가능한 칸으로 처리됩니다!)
- `#`: 벽

`maze_to_graph()`는 벽을 제외한 칸들을 노드로 만들고, 상하좌우로 이동 가능한
칸들을 간선으로 연결합니다. 예를 들어 `(0, 0)`에서 아래와 오른쪽으로 이동할 수
있다면, 그래프에는 다음과 비슷한 형태로 저장됩니다.

```python
graph[(0, 0)] = [(1, 0), (0, 1)]
```

이 과정을 거치면 미로 문제를 일반적인 그래프 탐색 문제처럼 다룰 수 있습니다.

### 2. 직접 구현한 큐*

```python
class Queue
```

BFS는 먼저 들어온 노드를 먼저 처리하는 FIFO(First In, First Out) 방식의 큐를
사용합니다. 파이썬 리스트도 큐처럼 사용할 수 있지만, 맨 앞 원소를 제거하는
`pop(0)`은 비효율적일 수 있습니다.

#### 리스트로 큐를 쓸 때의 문제

리스트에서 `pop(0)`을 실행하면 맨 앞 원소만 사라지는 것이 아니라, 뒤에 있던
원소들이 한 칸씩 앞으로 이동합니다.

```text
pop(0) 실행 전:  [A, B, C, D]
pop(0) 실행 후:  [B, C, D]

내부적으로는 B, C, D가 각각 한 칸씩 앞으로 이동한다.
```

원소가 4개면 3개를 옮기고, 1,000개면 999개를 옮겨야 합니다. **큐에 들어 있는
원소가 n개일 때 `pop(0)`은 O(n)이 됩니다.** BFS에서는 노드를 꺼내는 작업이 반복되기
때문에, 미로가 커질수록 이 비용이 누적될 수 있습니다.

#### head-tail 방식

이 코드에서는 각 값을 `_QueueNode`에 담고, 노드끼리 `next`로 연결합니다. 큐는
맨 앞을 가리키는 `head`와 맨 뒤를 가리키는 `tail`만 기억합니다.

```text
head                       tail
 ↓                          ↓
[A] → [B] → [C] → [D] → None
```

맨 앞 값을 꺼낼 때는 `head`를 다음 노드로 옮기기만 하면 됩니다.

```text
popleft() 실행 전:  head → [A] → [B] → [C] → None
popleft() 실행 후:          head → [B] → [C] → None
```

값을 추가할 때도 `tail` 뒤에 새 노드를 연결하고, `tail`을 새 노드로 옮기면 됩니다.

```text
append(D) 실행 전:  head → [B] → [C] → None
append(D) 실행 후:  head → [B] → [C] → [D] → None
                                           ↑
                                          tail
```

이 방식은 **기존 원소들을 이동시키지 않고** `head`와 `tail`만 바꾸므로,
**`append()`와 `popleft()`를 모두 O(1)에 처리**할 수 있습니다.

#### 메서드 정리

| 메서드 | 동작 | BFS에서의 역할 |
|---|---|---|
| `append(value)` | tail 뒤에 새 값을 추가한다 | 새로 발견한 이웃 노드를 큐에 넣는다 |
| `popleft()` | head 값을 꺼내고 head를 다음 노드로 옮긴다 | 다음에 탐색할 노드를 꺼낸다 |
| `is_empty()` | 큐가 비어 있는지 확인한다 | 탐색을 계속할지 판단한다 |
| `to_list()` | 현재 큐 상태를 리스트로 반환한다 | 상태 확인에 사용한다 |
| `__len__()` | 큐에 들어 있는 값의 개수를 반환한다 | `len(queue)`로 큐 크기를 확인한다 |

### 3. BFS 탐색

```python
bfs(graph, start, goal=None)
```

`bfs()`는 시작 노드에서 가까운 노드부터 차례대로 방문합니다.

탐색 중에는 세 가지 정보를 함께 관리합니다.

- `visited`: 이미 발견되어 큐에 들어간 노드 (큐에 넣는 시점에 바로 표시해서, 같은 노드가 중복으로 들어가는 것을 방지한다)
- `queue`: 앞으로 확인할 노드
- `parent`: 각 노드를 어디서 처음 발견했는지에 대한 기록

`goal`을 넣지 않으면 전체 탐색 순서만 확인할 수 있고, `goal`을 넣으면 목표 노드에
도착했을 때 최단 경로를 함께 반환합니다.

반환값은 다음 형태입니다.

```python
{
    "order": 탐색한 노드 순서,
    "path": 최단 경로 또는 None
}
```

### 4. 경로 복원

```python
reconstruct_path(parent, start, goal)
```

BFS가 새로운 노드를 발견할 때마다 `parent[neighbor] = current`를 저장합니다.
이 값은 “neighbor는 current를 통해 처음 발견되었다”는 뜻입니다.

목표점에 도착하면 `goal`에서 시작해 `parent`를 거꾸로 따라 올라갑니다.
그렇게 얻은 경로는 `G -> ... -> S` 방향이므로, 마지막에 `reverse()`를 사용해
`S -> ... -> G` 순서로 뒤집습니다.

> [!NOTE]
> `parent`는 각 노드가 "누구에게 발견되었는가"를 저장하므로, 한 노드에서
> 따라갈 수 있는 방향은 start 쪽뿐입니다. start에서 goal 방향으로는
> 하나의 노드가 여러 이웃을 발견할 수 있어 어느 쪽이 goal로 이어지는지
> 알 수 없습니다. 그래서 경로 복원은 goal에서 start로 역추적한 뒤
> 뒤집는 방식만 가능합니다.

## 사용 방법

`bfs.py`의 함수들을 사용해 미로를 그래프로 변환한 뒤 BFS를 실행할 수 있습니다.

```python
maze = [
    list("S.."),
    list(".#."),
    list("..G"),
]

graph, start, goal = maze_to_graph(maze)
result = bfs(graph, start, goal)

print(result["path"])
# [(0, 0), (1, 0), (2, 0), (2, 1), (2, 2)]  와 같은 형태로 출력

## 시간 복잡도

그래프의 노드 수를 `V`, 간선 수를 `E`라고 하면 BFS의 시간 복잡도는 보통
`O(V + E)`입니다.

각 노드는 한 번씩 방문되고, 각 간선도 탐색 과정에서 한 번씩 확인되기 때문입니다.
이 코드에서는 큐를 직접 구현해 `popleft()`를 O(1)에 처리하므로, 리스트의
`pop(0)`을 사용할 때 생길 수 있는 불필요한 비용을 줄였습니다.

## 예외 처리

`None`을 반환합니다.

- 미로의 행 길이가 서로 다를 때

- `start`가 그래프 안에 없을 때
- `goal`이 지정되었지만 그래프 안에 없을 때
- `goal`까지 도달할 수 있는 경로가 없을 때

## 정리

이 구현의 핵심은 미로를 그래프로 변환한 뒤, BFS가 가까운 노드부터 탐색한다는
특성을 이용하는 것입니다. 이동 비용이 모두 같은 미로에서는 이 방식으로 최단
경로를 찾을 수 있습니다.
